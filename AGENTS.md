# AGENTS.md

Guidance for coding agents other than Claude Code (including Codex). Follow [CLAUDE.md](CLAUDE.md) for the shared scientific and repository policies, irrespective of the coding assistant.

- Read the relevant issue and research documents before edits.
- Start a branch, make small changes, test, open a PR for human review; no unsolicited merges to `main`.
- Coordinate independent reviews in separate branches or worktrees. Do not have two agents edit the same working tree simultaneously.
- Clearly distinguish **planned** from **implemented** features and **verified** from **unverified** claims.
- Protect credentials, data licenses, 3D asset rights, and geographic provenance.
- Lead/issue assignee: `@mapbytomoya`.
